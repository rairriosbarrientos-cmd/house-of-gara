# Modelos GLB oficiales GARA

Esta carpeta recibirá los GLB exactos de los patrones físicos. No colocar modelos genéricos.

Nombres previstos:
- tarjetero-duo-naranja-marino.glb (una sola pieza — el reverso/vintage café es la cara trasera de este mismo modelo, no un modelo aparte)
- tarjetero-firma-gara.glb
- bifold-vintage-cafe.glb
- bifold-duo-naranja-azul-hielo.glb
- tarjetero-animal-print.glb

Convención obligatoria de nombres de malla/material:
- PRIMARY_*: piel principal / exterior
- SECONDARY_* o INTERIOR_*: piel secundaria / interior
- ACCENT_* o BRIDGE_*: acentos y puente
- THREAD_* o STITCH_*: costura
- EDGE_* o PAINT_*: canto pintado
- HARDWARE_*: herrajes metálicos

El visor GLBProductViewer asigna materiales dinámicos según estos nombres.
